# Minimalism Brown theme artwork

These files were extracted from a third-party template during development so
the layout and proportions could be matched exactly.

**They must be replaced with self-generated equivalents of the same
composition before public launch.** Shipping them as-is carries copyright
exposure. This is a launch blocker, not an implementation blocker.

See `docs/superpowers/specs/2026-09-18-minimalism-brown-template-design.md`.

## Intrinsic dimensions
